# PhishScope

一个离线优先的钓鱼邮件分析器。给它一封可疑邮件，输出一份带风险评分、判断依据和 IOC 清单的报告。

## 要解决的问题

安全人员手工研判一封上报的钓鱼邮件，得逐封看邮件头、核验发件人是不是它声称的身份、
判断链接和附件有没有问题。单封通常要 5–15 分钟，而且很看个人经验。

## 项目目标

- 解析 `.eml` 文件和粘贴的原始邮件
- 查邮件头里的伪造痕迹：显示名冒充品牌、Reply-To 和 From 对不上等等
- 读 `Authentication-Results`，把 SPF / DKIM / DMARC 的真实结论报出来
- 比对链接的显示文字和真实地址，这是最常见的钓鱼特征
- 看附件：扩展名和真实文件类型是否一致、有没有内嵌宏

目标是最后给出一个 0–100 的分数，同时把每一条扣分的依据一起给出来，
而不是丢一堆原始信号让人自己去猜。

中文场景是重点之一：中文诱导话术、国内品牌仿冒、国内免费邮箱。
现有的开源工具基本只覆盖英文。

## 两条硬约束

- **默认不联网**，邮件内容不出本机
- **绝不执行附件**，只做字节层面的静态检查
